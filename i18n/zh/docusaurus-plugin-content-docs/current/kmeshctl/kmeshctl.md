## kmeshctl

用于运维和调试 Kmesh 的命令行工具

### 选项

```bash
  -h, --help   help for kmeshctl
```

### 另请参阅

* [kmeshctl authz](kmeshctl_authz.md) - 管理用于 Kmesh 授权卸载的 xdp authz eBPF 程序
* [kmeshctl dump](kmeshctl_dump.md) - 转储内核原生模式或双引擎模式的配置
* [kmeshctl log](kmeshctl_log.md) - 获取或设置 kmesh-daemon 的日志级别
* [kmeshctl monitoring](kmeshctl_monitoring.md) - 按需控制 Kmesh 监控功能的开启与关闭
* [kmeshctl secret](kmeshctl_secret.md) - 使用 secrets 管理 IPsec 的密钥配置数据
* [kmeshctl version](kmeshctl_version.md) - 打印构建版本信息
* [kmeshctl waypoint](kmeshctl_waypoint.md) - 管理 waypoint 配置
