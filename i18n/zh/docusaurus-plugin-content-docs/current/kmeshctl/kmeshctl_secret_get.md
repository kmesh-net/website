## kmeshctl secret get

通过 kmeshctl 获取 IPsec 密钥与配置

```bash
kmeshctl secret get [flags]
```

### 示例

```bash
# 通过 kmeshctl 获取 IPsec 密钥与配置。结果将以 JSON 格式显示。
kmeshctl secret get
```

### 选项

```bash
  -h, --help   help for get
```
