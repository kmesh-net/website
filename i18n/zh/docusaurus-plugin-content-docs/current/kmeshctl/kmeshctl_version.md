## kmeshctl version

打印构建版本信息

```bash
kmeshctl version [flags]
```

### 示例

```bash
# 显示所有 kmesh 组件的版本
kmeshctl version

# 显示特定 kmesh daemon 的版本信息
kmeshctl version <kmesh-daemon-pod>
```

### 选项

```bash
  -h, --help   help for version
```
